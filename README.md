# 授業スタンプシステム フロントエンド

## テスト環境
- Node.js 24.11.0
- npm 11.6.1
- Vite 7.2.2

## 実行
```bash
npm i
npm run dev
```

## 認証・ログアウト機能

### 概要
このアプリケーションはMicrosoftアカウント認証（Spring Security OAuth2）を使用しています。

### ログアウト機能
ログアウトボタンをクリックすると、以下の処理が実行されます：
1. バックエンドの `/logout` エンドポイントにPOSTリクエストを送信してサーバー側のセッションを破棄
2. クライアント側の認証状態（`appData`）をクリア
3. ユーザーをログイン画面にリダイレクト

### 動作確認手順
1. アプリケーションを起動し、Microsoft アカウントでログイン
2. ダッシュボードが表示されることを確認
3. 右上の「ログアウト」ボタンをクリック
4. ボタンが「ログアウト中...」と表示され、無効化されることを確認
5. ログイン画面に戻ることを確認
6. ブラウザの開発者ツール（Application > Cookies）でセッションCookieがクリアされていることを確認

### 注意事項
- ログアウト機能を正常に動作させるには、バックエンドサーバーが起動している必要があります
- バックエンドの `/logout` エンドポイントが正しく設定されている必要があります
- ログアウト処理中にエラーが発生した場合でも、クライアント側の状態はクリアされ、ログイン画面に戻ります
